# Дом мёда — прототип новой версии сайта

Next.js 16 (App Router, Cache Components) + Tailwind CSS 4. Структура, тексты, фото и способ покупки — с текущего
сайта www.dommeda.ru; новая только подача. Принципы дизайна: [`../docs/design/principles.md`](../docs/design/principles.md).

## Запуск

```bash
npm install
npm run dev          # http://localhost:3000
npm run build && npm start   # как на проде
```

Данные и фото уже лежат в репозитории (`data/`, `public/media/`, `public/brand/`). Пересобрать их из копии старого
сайта (`../site`) и мок-бэкенда (`../mock-backend/data`):

```bash
npm run sync-data
```

## Что работает

| | |
|---|---|
| Главная | первый экран с сортами, факты о магазине, медовая шкала «от светлого к тёмному», свежий сбор с покупкой прямо с витрины, магазин и дегустация, доставка, пчеловодам |
| Каталог мёда | все 47 позиций, фильтр по вкусу (нежные / насыщенные / с горчинкой), сортировка, разделы |
| Сорт | цвет на шкале, характер, аромат и вкус, товары сорта, описание со старого сайта |
| Товар | галерея, фасовки кнопками с ценой, цена за 100 г, количество, «В корзину», закреплённая кнопка на мобильном, доставка, свойства, похожие |
| Пчеловодам | 105 товаров, подразделы, объявление о записи на пчелопакеты |
| Корзина | выдвижная панель, хранится в браузере (localStorage) |
| Оформление | контакты, способ получения (курьер / за МКАД / самовывоз), адрес, оплата, комментарий, фирменный пакет 15 ₽; валидация как на старом сайте |
| Формы | «Перезвоните мне» (шапка, мобильное меню), обратная связь на «Контактах» |
| Прочее | поиск (ё = е), «О магазине», «Доставка и оплата», оферта, политика, 404 |

API прототипа (`app/api/*`): `POST /api/orders` (сумма пересчитывается по каталогу, цены из браузера игнорируются),
`POST /api/callback`, `POST /api/feedback`. Заявки и заказы **никуда не отправляются** — пишутся в лог сервера
(на Vercel — вкладка Logs). Для боевого режима их нужно отправлять в CRM/почту/1С.

## Ограничения прототипа — уточнить у заказчика

- **Сорта** (`lib/varieties.ts`): цвет, характер и короткие описания собраны из текстов сайта — подтвердить.
- **Доставка и оплата** (`data/settings.json`): названия способов и цена «за МКАД» восстановлены по старому JS — сверить.
- **Акции**: цены в блоке акций на главной старого сайта не совпадают с ценами товаров (например, акация 3 950 ₽ в баннере
  и 4 025 ₽ в карточке) — в прототипе показаны цены каталога, блок «по акции» не перенесён.
- **«Рецепты» и «Музей»**: на старом сайте 404 — в прототипе аккуратные заглушки.
- **Логотип** — растровый из старого `logo.png`; нужен вектор. Фото магазина — со страницы «О нас» (2014 г.), нужна свежая съёмка.
- Facebook и Instagram из подвала убраны (заблокированы в РФ), оставлены ВКонтакте и Одноклассники.
- Сайт закрыт от индексации (`robots: noindex`) — это прототип.

## Устройство

```
app/                 страницы (App Router) и API
components/          интерфейс: header/, cart/, checkout/, catalog/, forms/, content/
lib/catalog.ts       доступ к каталогу (data/catalog.json)
lib/cards.ts         данные карточек (на сервере — клиент не тянет весь каталог)
lib/varieties.ts     сорта: цвет, вкус, описание (редакционные данные)
lib/validation.ts    правила форм — общие для браузера и API
scripts/sync-data.mjs  подготовка данных и фото (WebP 480/960, обрезка белых полей, точка фокуса)
```

## Деплой на Vercel

Проект в подпапке `web/` — при импорте репозитория указать **Root Directory = `web`**. Переменные окружения не нужны.
